# 隐私说明

本说明描述 Galatea Link mobile 当前版本的数据处理边界，正式发布前可据此制作 `galatea.noctfom.top` 上的公开隐私政策页面

## 本地保存的数据

- YDK 卡组、GKG 模型包解包结果、ONNX 模型和导入的 `cards.cdb`
- 游戏服务器地址、端口、房间编号、玩家名、决策策略和界面偏好
- 最近七天的脱敏诊断日志，用户可主动导出或清除
- 房间密码和 LLM API Key，使用 Android 系统安全存储保存

保存空房间密码会删除同名配置以前保存的密码。删除卡组、模型、卡片数据库、配置或日志只影响本机应用私有数据

## 发生网络传输的场景

- 连接用户指定的 MDPro3/YGOPro 游戏服务器时，按游戏协议发送登录信息、房间信息、玩家名、卡组和合法响应
- 启用并触发 LLM 决策时，向用户配置的 API 地址发送当前玩家通过在线协议可见的对局状态、合法动作、必要卡片语义和受限聊天上下文
- 用户在设置页点击检查更新时，向 `https://galatea.noctfom.top/mobile/update.json` 请求稳定版清单

应用不尝试获取或上传对手隐藏区域的内容，不包含广告 SDK、统计 SDK、崩溃遥测或账号跟踪。游戏服务器和 LLM 服务各自的数据处理规则由对应服务提供者决定

## 剪贴板与文件

应用只在前台启动后检查一次剪贴板，并且仅在内容像 YDK 文本、YDKe 卡组码或支持的卡组分享链接时提示用户确认导入。用户拒绝后不会保存内容

通过系统文件选择器打开 YDK、GKG 或 CDB 时，应用只读取用户明确选择的文件并复制到应用私有目录，不申请读取整个共享存储空间

## 权限用途

- 网络权限用于游戏服务器、用户配置的 LLM API 和手动版本检测
- 通知与前台服务权限用于对局连接期间保持响应
- 唤醒锁用于活动对局中的短时后台执行

应用不申请通讯录、定位、相机、麦克风或整盘存储权限

## 联系与变更

问题和数据删除请求可通过项目 GitHub Issue 提交。隐私边界发生实质变化时，应随版本更新本文件和公开网页并在发布说明中标注

本项目不是 Konami、MDPro3、YGOPro 或相关游戏服务的官方产品
