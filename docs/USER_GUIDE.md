# Galatea Link mobile 使用文档

Galatea Link mobile 可以在 Android 设备上直接连接 MDPro3/YGOPro 游戏服务器，并在本机运行 Core ONNX 模型、LLM 或混合决策，不依赖电脑端 Galatea Link 和 AstrBot

## 连接手机本机 YGOMobile

1. 先在 Galatea Link mobile 中选择有效的 YDK 卡组
2. 点击“手机本机 YGOMobile”
3. 应用会自动使用 `172.19.0.1:7911`、房间编号 `0`，并清除当前保存的房间密码
4. 应用立即进入等待界面，每 5 秒尝试连接一次，最多等待 5 分钟
5. 切换到同一台手机上的 YGOMobile 并创建本地房间
6. 连接成功后应用会上传卡组、准备并在房主身份下尝试开始对局

等待期间 Android 会显示前台保活通知，可以切换到 YGOMobile 操作。点击概览页右上角退出按钮或等待卡片中的“取消”即可停止重试。五分钟内没有建立房间时应用会自动断开

`172.19.0.1` 是 YGOMobile 为同设备本地联机提供的地址，不等于普通 Android 回环地址。Android 模拟器访问电脑服务通常使用 `10.0.2.2`，实体机访问电脑则应填写电脑的局域网地址

手动填写 `172.19.0.1:7911` 后点击“连接游戏”也会进入相同的五分钟等待流程，并清除当前密码，避免从等待页返回后再次连接时丢失自动重试状态

## 连接在线服务器

在连接页填写服务器地址、端口、房间编号、房间密码和玩家名称，选择卡组后点击连接。可以将常用参数保存为命名配置，空密码会删除该配置先前保存的密码

普通服务器只在收到入房确认后进入对局概览。TCP 已建立但服务器十二秒内没有确认房间、服务器主动关闭或返回网络错误时，应用会留在连接页并显示具体错误，不会先进入空白状态页

## 卡组与卡片资料

- 支持导入、查看、编辑和删除 YDK 卡组
- 支持从卡组文本或剪贴板识别可用卡组
- 支持导入 YGOPro `cards.cdb`，用于显示卡名和辅助语义
- Android 可以将 `.ydk`、`.gkg` 和 `.cdb` 文件分享或交给本应用打开

## Core 与 LLM

- Core 模式使用安装到应用内的 GKG/ONNX 模型
- LLM 模式使用设置页配置的兼容 API
- 混合模式依据 Core 置信度和指定时点决定是否调用 LLM
- Core 温度范围为 `0.05` 到 `2.00`，自对局常用值约为 `0.20`
- LLM 只接收当前玩家通过游戏协议可见且决策需要的数据

## 日志与更新

设置页可以查看、导出或清空近期脱敏诊断日志。日志会自动轮换，并记录服务器卡组拒绝详情、决策管线、Core 编码与 ONNX 推理的分段耗时；遇到实体设备专有问题时请先导出日志再反馈

设置页的更新检查只读取 `galatea.noctfom.top` 提供的 HTTPS 版本清单，下载和安装由系统浏览器处理
